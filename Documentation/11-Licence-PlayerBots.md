# Licence du module cmangos/playerbots

État au 2026-10-23 : le dépôt https://github.com/cmangos/playerbots ne publie **aucun fichier de licence**. Sans
licence, le droit d'auteur s'applique par défaut : on peut utiliser le module pour soi (compiler, jouer), mais pas
le **redistribuer** (package HomeCraft contenant mangosd.exe compilé avec le module) sans l'accord de ses auteurs.

Le cœur CMaNGOS (mangos-classic) est sous GPL-2.0 : le module y est lié statiquement dans mangosd.exe, ce qui
rend l'ensemble compatible GPL-2.0 seulement si les auteurs du module l'acceptent.

Tant que la réponse n'est pas obtenue, l'édition CMaNGOS reste **à usage personnel** (aucune diffusion du package).

>
